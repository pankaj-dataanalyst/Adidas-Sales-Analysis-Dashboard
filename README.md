# Adidas Sales Analysis – Power BI Dashboard
## 📊 Project Overview
This project presents an **Adidas Sales Analysis Dashboard** developed using Microsoft Power BI.
The dashboard provides an interactive view of sales performance across different months, regions, states, products, retailers, years, and sales channels.

## 🎯 Project Objectives
* Analyze overall sales and profit performance.
* Identify monthly sales trends.
* Compare sales across regions and states.
* Analyze product-wise sales performance.
* Compare sales across different retailers.
* Analyze sales by year and sales channel.
* Provide interactive filters for better business analysis.

## 🛠️ Tools & Technologies
* Microsoft Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Visualization

## 📌 Dashboard Features
### Key Performance Indicators
The dashboard includes:
* Total Sales
* Total Profit
* Total Units Sold
* Average Price
* Average Profit

### Sales Analysis
* Monthly Sales Trend
* State-wise Sales
* Region-wise Sales
* Product-wise Sales
* Retailer-wise Sales
* Year-wise Analysis
* Sales Channel Analysis

## 📈 Business Insights
The dashboard can be used to understand:
* How sales change throughout the year.
* Which regions contribute to overall sales.
* Which products generate higher sales.
* Which retailers contribute significantly to sales.
* Differences between sales channels.
* Overall sales and profitability performance.

## 🔍 Interactive Filters
The dashboard provides interactive filtering options that allow users to analyze the data based on available years and sales channels.
